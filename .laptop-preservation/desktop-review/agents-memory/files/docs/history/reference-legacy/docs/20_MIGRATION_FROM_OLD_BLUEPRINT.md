# 20 — Migration from the Earlier Blueprint

## What remains valid

- tool specialization;
- explicit rules;
- project detection;
- evidence-first behavior;
- read-only defaults;
- validation before success;
- verified memory;
- LBE governance.

## What changed

### Earlier framing

A broader maintenance agent that could plan, repair, edit, and learn across projects.

### Current framing

A focused Guard Inspector that:

- retrieves indexed knowledge;
- inspects current evidence when needed;
- selects deterministic guards;
- returns evidence-backed verdicts;
- proposes workspace protection only with user approval.

## Deferred capabilities

- broad autonomous repair;
- automatic global-rule creation;
- unrestricted planning;
- passive learning from the corpus;
- model-generated verdicts;
- checkpoint implementation beyond documentation.

## Authoritative implementation order

1. retrieval quality;
2. typed contracts;
3. one deterministic vertical slice;
4. workspace resolution;
5. guard catalog;
6. small reasoning agent;
7. governed workspace-rule proposals;
8. protected checkpoint behavior;
9. optional repair.
