# Governance Agent Authority

This directory contains governance-only authority for validation and agent preflight work.

## Active Index

Agents must use:

```text
docs/governance/DOC_INDEX.json
```

Do not use `docs/agents/DOC_INDEX.json`; it is not an active authority in this workspace.

## Required Registration Path

Enhancements must be registered through `docs/governance/ENHANCEMENT_REGISTRATION.md` and the machine-readable registries it names before implementation changes are treated as valid.
